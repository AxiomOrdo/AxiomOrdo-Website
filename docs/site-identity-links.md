# Shared company identity links

Every AxiomOrdo-owned public site must include this link in its site-wide footer:

- Label: `ICO registration ZC216112`
- URL: `https://www.axiomordo.com/legal/ico-registration/`

The AxiomOrdo page is the canonical location for the registration details and certificate. Future sites must link to it rather than publishing another copy of the PDF.

Before releasing a new site, verify that the footer link returns HTTP 200 and that the certificate link on the canonical page opens successfully.
